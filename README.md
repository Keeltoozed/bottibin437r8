# Smart Money Trading Bot

## Описание
Telegram-бот для автоматической торговли на Binance по сигналам Smart Money из Telegram-канала.

## Настройка

1. Установить зависимости:
```bash
npm install
```

2. Настроить `.env` файл:
- `BINANCE_API_KEY` / `BINANCE_SECRET` — ключи Binance
- `TELEGRAM_BOT_TOKEN` — токен Telegram бота
- `TELEGRAM_CHAT_ID` — ID чата для уведомлений
- `TELEGRAM_SIGNAL_CHANNEL_ID` — ID канала с сигналами
- `TRADE_AMOUNT_USDT` — сумма входа в сделку (USDT)
- `LEVERAGE` — плечо
- `USE_TESTNET` — использовать тестовую сеть

## Запуск
```bash
npm start
```

## Команды бота
- `/status` — статус открытых позиций
- `/balance` — баланс аккаунта
- `/close` — закрыть все позиции
- `/setamount <sum>` — изменить сумму входа
- `/setleverage <lev>` — изменить плечо
- `/pause` — приостановить торговлю
- `/resume` — возобновить торговлю

## Логика работы

### Парсинг сигналов
Бот мониторит Telegram-канал и парсит сигналы формата:
- Пара (например VANA/USDT)
- Точка входа (Entry)
- TP1, TP2, TP3 — тейк-профиты
- Стоп-лосс (SL)

### Вход в позицию
- Вход на фиксированную сумму (`TRADE_AMOUNT_USDT`), независимо от плеча
- Плечо устанавливается заранее
- Сейф при 50% пути к TP1 (перемещение SL в безубыток)

### Управление позицией
- При достижении TP1 — закрытие 50% позиции, SL в безубыток
- При достижении TP2 — закрытие ещё 25%
- При достижении TP3 — закрытие остатка
- Команда "Закрываем СЕЙЧАС" — немедленное закрытие
